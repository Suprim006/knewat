# Acme Notes API: product brief

Acme Notes is a small notes service for the fictional company Acme Corp. Teams create notes, tag them, and
search them by tag or text. The first release is a REST API only (no UI).

- Goal: a notes REST service ready for internal pilot in six weeks.
- Scope: create, read, update, delete and list notes; tags; full-text search is a later phase.
- Owner: the Acme Platform team.
- Rate limit: 100 requests per minute per client.
